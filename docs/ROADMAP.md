# Roadmap

## Phase 0 — completed in this scaffold

- rights-aware source intake;
- deterministic story-to-scene vertical slice;
- production roles and work orders;
- downstream media manifests;
- independent validator, tests, CLI, and CI workflow.

## Phase 1 — useful pre-production

- provider interface package and JSON-schema versioning;
- chapter-aware book ingestion with page/paragraph provenance;
- screenplay revision loop with human approvals;
- character, location, prop, wardrobe, and continuity databases;
- budget, schedule, and provider-cost estimation.

## Phase 2 — media production adapters

- consent-aware TTS adapter and pronunciation dictionary;
- image/video generation adapter with seed and reference tracking;
- motion-graphics template renderer;
- sound/music adapter with clearance ledger;
- NLE timeline export and proxy media management.

## Phase 3 — feature-length pilot

- one rights-cleared 80–110 minute pilot;
- automated continuity and audio-sync checks;
- human review checkpoints at script lock, casting lock, picture lock, and final QC;
- measured cost, latency, rejection rate, and revision hours.
